## 目标

从公开组学资源出发，把多株植物的蛋白/CDS 整理齐，再依次：**找同源基因 → 看染色体上的共线性区块 → 用单拷贝等建亲缘树 → 推断全基因组加倍（WGD）及加倍相关共线性**。

### 阶段 3 用语约定（生物基因组学语境）

阶段 3 **不叫「跑一下 BLAST」就完事**，而是：**在可比的蛋白（或 CDS）集合上，鉴定同源基因，并整理成下游共线性软件能吃的命中表**。

- **输入**：阶段 2 过关后的蛋白序列（及配套基因位置信息）；种间比较、种内（旁系）比较按课题需要分别做。
- **常见做法**：BLASTP / DIAMOND 等做全对全或指定种对搜索；按 e-value、比对覆盖、相似度等过滤；可保留双向最优命中（RBH）或按共线性工具（如 WGDI）要求的 outfmt 输出。
- **产出一句话**：一张「基因 A ↔ 基因 B、有多像、怎么比上的」同源对表，并写明过滤规则与软件版本。
- **不要混进本阶段**：共线性区块识别、Ks、建树——那些是阶段 4–6。

## 全局约定

- **目录**：`raw/` → `clean_v2/`/`analysis_v2/` → `blast/` → `synteny/` → `tree/` → `wgd/`（`references/project-layout.md`）；阶段 1 工作区可对应 `plant-genome-resources/`
- **命名**：学名缩写/固定代码；组装版本写进路径或资源表
- **可复现**：每阶段留命令/参数与软件版本
- **停机**：分界检查不过 → 不进下一阶段，先修本阶段或回子 skill

## 怎么用

1. 新项目：阶段 0 → **过 0→1** → 阶段1子 skill → **过 1→2** → 阶段2子 skill → **过 2→3** 再往下。
2. 只做下载：确认 0→1 后进 [植物组学资源检索与下载](sand-workflow:skill-1793405308920)。
3. 阶段 2 已对接上游 WGDI 预处理；阶段 3 及以后子 skill 未建时，按本表分界与用语手工推进，建好后填进阶段总览表。
