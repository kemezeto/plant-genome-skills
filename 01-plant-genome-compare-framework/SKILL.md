skill-1793405456014/

> 本 skill 管**阶段顺序与分界点**；子 skill 管**阶段内怎么做**。改流程先改本框架分界表，再改对应子 skill。

## 目标

从公开组学资源出发，完成多植物：同源（BLAST）→ 共线性 → 亲缘/系统发育树 → 全基因组加倍（WGD）推断及加倍相关共线性。

## 阶段总览 ↔ 子 skill

| 阶段 | 做什么 | 主要产出 | 子 skill |
|------|--------|----------|----------|
| 0. 立项与物种集 | 定目标/对照物种、科学问题 | 物种列表、问题一句话 | （本框架） |
| 1. 资源检索与下载 | 找链接、定版本、下载校验 | 链接表 + 原始文件 | [植物组学资源检索与下载](sand-workflow:skill-1793405308920) |
| 2. 数据预处理 | 清洗、统一染色体名、提 CDS/蛋白 | `clean/` | [植物基因组数据预处理](sand-workflow:skill-1793419436579)（骨架） |
| 3. BLAST / 同源 | 种间/种内同源与过滤 | 同源对表 | 待建 |
| 4. 共线性 | 区块识别与可视化 | 区块、图 | 待建 |
| 5. 亲缘与系统发育 | 单拷贝等建树 | 树、支持率 | 待建 |
| 6. WGD 与加倍共线性 | Ks/共线性深度等 | WGD 假设、加倍共线性 | 待建 |

## 分界点（过关才进入下一阶段）

| 分界 | 出口检查（上一阶段做完） | 下一棒 |
|------|--------------------------|--------|
| **0→1** | 物种表 + 科学问题 + 需要的文件类型（cds/gff/pep…） | [资源检索与下载](sand-workflow:skill-1793405308920) |
| **1→2** | 版本/链接表齐全；目标种下载目录有所需类型（或已记缺失）；inventory 已刷新 | [数据预处理](sand-workflow:skill-1793419436579) |
| **2→3** | `clean/` 命名统一；染色体对照表齐 | BLAST（待建） |
| **3→4** | 过滤同源对表 + 规则/版本记录 | 共线性（待建） |
| **4→5** | 共线性区块可用；图抽查过 | 系统发育（待建） |
| **4/5→6** | 共线性就绪；（可选）树作背景 | WGD（待建） |
| **6 完** | WGD 假设与加倍共线性有解读要点 | 归档 / 回框架复盘 |

完整交接表见 `references/phase-checklist.md`。

## 全局约定

- **目录**：`raw/` → `clean/` → `blast/` → `synteny/` → `tree/` → `wgd/`（`references/project-layout.md`）；阶段 1 工作区可对应 `plant-genome-resources/`
- **命名**：学名缩写/固定代码；组装版本写进路径或资源表
- **可复现**：每阶段留命令/参数与软件版本
- **停机**：分界检查不过 → 不进下一阶段，先修本阶段或回子 skill

## 怎么用

1. 新项目：阶段 0 → **过 0→1** → 阶段1子 skill → **过 1→2** → 阶段2子 skill → **过 2→3** 再往下。
2. 只做下载：确认 0→1 后进 [植物组学资源检索与下载](sand-workflow:skill-1793405308920)。
3. 预处理目前为骨架（脚本暂空），按检查点手工推进亦可；脚本补齐后仍走同一分界。
4. 更后段子 skill 未建：按分界表手工推进，建好后填进阶段总览表。
